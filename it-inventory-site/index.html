Comment utiliser IT-Inventory

Guide pas a pas pour les techniciens Android.

Questions frequentes

L'app fonctionne-t-elle sur n'importe quel Android ? +

Oui. IT-Inventory fonctionne sur tout Android 8.0+. Elle etait auparavant optimisee pour Zebra TC22, mais elle est desormais concue pour les telephones Android classiques avec la camera pour le scan.

Puis-je utiliser l'app sans connexion internet ? +

En mode hors-ligne, vous pouvez consulter le stock. La synchronisation des operations necessite une connexion pour s'enregistrer dans la base Supabase.

Comment scanner un code-barres avec mon telephone Android ? +

Depuis le Dashboard, appuyez sur le bouton Scanner (icone QR central). Autorisez la camera, puis pointez le code-barres de l'article.

Comment changer de site actif (Stock 5eme vers Stock 8eme) ? +

Sur le Dashboard, tapez sur la pill verte affichant votre site actuel en haut a gauche. Choisissez ensuite le site souhaite parmi Epinal, Stock 5eme, Stock 8eme, TCS.

Comment declarer un PC en panne ? +

Dans l'onglet Parc PC, trouvez le PC concerne et appuyez sur En panne. Choisissez type, priorite et description, puis confirmez.

Comment mettre a jour l'application ? +

Ouvrez le Google Play Store, recherchez IT-Inventory puis appuyez sur Mettre a jour. En cas de mise a jour obligatoire, l'app affiche un ecran de mise a jour forcee.
